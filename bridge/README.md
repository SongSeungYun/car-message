# 맥 음성 브리지 (bridge/)

에뮬레이터 안에서는 Pleos 음성 인식·읽기(STT/TTS)가 동작하지 않는다(`ON_DEVICE_ENGINE_ERROR`).
그래서 맥이 대신 듣고, 대신 읽어 준다. 신호 형식은 `docs/device-signals.md`를 따른다.

```
[아두이노 버튼] --USB 시리얼--> [브리지] --adb broadcast--> [A차 앱]
                                   ^
[B차 앱] --POST 10.0.2.2:8090/speak-+--> 맥 스피커(say)
```

| 할 일 | 신호 |
|---|---|
| 버튼 누름 | 앱에 `PTT state=DOWN` 보내고 녹음 시작 |
| 버튼 뗌 | 녹음 끝 → 한국어 인식 → 앱에 `VOICE_RESULT text=...` (PTT UP은 안 보냄) |
| 앱이 읽기 요청 | `POST /speak {"car":"B","text":"좌회전합니다"}` → 204, 맥이 소리 내어 읽음 |

## 인식 결과 다듬기

앱은 지금 `N번 메시지 보내줘`(N = 1~10)와 `재전송해줘`만 알아듣는다.
그래서 브리지가 인식 결과를 이 문장으로 맞춰서 보낸다.

- `삼번 메시지 보내 줘`, `세 번 메세지 보내줘`, `3번 전송해줘`, `3번` → `3번 메시지 보내줘`
- `이번 메시지 보내줘` → `2번 메시지 보내줘` (인식기가 "2번"을 "이번"으로 쓰는 경우 대비)
- `재전송해 주세요`, `다시 보내줘` → `재전송해줘`
- 그 밖의 말은 그대로 보낸다 (앱이 무시함)

문구로 고르기("좌회전 보내줘")는 다음 단계에서 다듬을 부분이다.

## 주의: 앱 듣기 시간 5초

앱은 `PTT DOWN`을 받은 뒤 5초가 지나면 듣기를 끝내고, 그 뒤에 온 결과는 버린다
(`fe/.../MessagingController.java`의 `VOICE_TIMEOUT_MS`).
버튼을 누른 시간 + 인식 시간이 5초를 넘으면 브리지 로그에 경고가 뜬다. 짧게 말하면 된다.

## 처음 설치 (맥, 노트북마다 한 번)

아래 명령은 저장소의 `bridge` 폴더로 이동한다.

```
cd ~/car-message/bridge
```

파이썬은 **3.12**를 쓴다(3.10~3.13 가능). 3.14 이상은 음성 인식 라이브러리가 쓰는 `onnxruntime`이 아직 없어 설치가 실패한다(3.15에서 실제로 실패 확인).
3.12가 있는지 확인한다. 경로가 나오면 있는 것이다.

```
which python3.12
```

없으면 Homebrew로 설치한다.

```
brew install python@3.12
```

파이썬 3.12로 가상환경(이 폴더 전용 설치 공간)을 만든다.

```
python3.12 -m venv .venv
```

가상환경을 켠다. 새 터미널을 열 때마다 다시 켜야 한다.

```
source .venv/bin/activate
```

필요한 라이브러리를 설치한다.

```
pip install -r requirements.txt
```

환경을 점검한다. 한국어 목소리, adb, 아두이노 포트, 마이크가 보이는지 확인한다.

```
python voice_bridge.py --check
```

- 한국어 목소리가 "없음"이면: 시스템 설정 → 손쉬운 사용 → 읽기 및 말하기 → 시스템 목소리에서 한국어(예: Yuna)를 내려받는다.
- 처음 녹음할 때 맥이 마이크 권한을 묻는다. 터미널에 허용한다.
- 처음 실행할 때 음성 인식 모델(small, 약 0.5GB)을 내려받는다. 인터넷이 필요하고 몇 분 걸린다.

## 실행

읽기 소리만 먼저 들어 본다.

```
python voice_bridge.py --say "좌회전합니다"
```

아두이노 없이 키보드로 시험한다. A차 에뮬레이터(emulator-5554)와 앱이 켜져 있어야 한다.
Enter를 누르고 "3번 메시지 보내줘"라고 말한 뒤 다시 Enter를 누른다.

```
python voice_bridge.py --keyboard
```

노트북 1(아두이노가 꽂힌 쪽, A차)에서 실제로 쓰는 명령이다. 아두이노 포트는 자동으로 찾는다.

```
python voice_bridge.py
```

노트북 2(B차)에서는 읽기만 하면 된다.

```
python voice_bridge.py --speak-only
```

## 옵션

| 옵션 | 기본값 | 뜻 |
|---|---|---|
| `--serial-port` | `auto` | 아두이노 포트. `/dev/cu.usbmodem...`로 직접 지정 가능 |
| `--keyboard` | | 아두이노 대신 Enter로 버튼 흉내 |
| `--adb-serial` | `emulator-5554` | 버튼 신호를 받을 에뮬레이터 (A차) |
| `--port` | `8090` | `/speak` 받는 포트 |
| `--speak-only` | | 읽기만 (버튼·인식 없음) |
| `--model` | `small` | 인식 모델. 느리면 `base`, 틀리면 `medium` |
| `--voice` | `auto` | 읽는 목소리. auto = 첫 한국어 목소리 |
| `--dry-run` | | adb 명령을 실행하지 않고 화면에만 출력 |
| `-v` | | 자세한 로그 |

## 시험

라이브러리 없이 도는 단위 테스트(다듬기, adb 명령, /speak, 버튼 흐름).

```
python3 -m unittest -v test_voice_bridge.py
```

## 아두이노

`firmware/ptt_button/ptt_button.ino`: 버튼 한쪽은 D2, 다른 쪽은 GND.
누르면 `BTN:DOWN`, 떼면 `BTN:UP`을 115200 bps로 보낸다.
아두이노는 포트를 열 때 재시작하므로 브리지는 연결 후 2초 기다린다.
