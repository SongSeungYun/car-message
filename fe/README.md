# 차량 메시지 시연 앱

현대차 공모전의 차량 간 송신 화면과 수신 알림을 Kotlin Android UI와 Java 상태 처리 코드로 구현한 프로젝트입니다. [Figma 시안](https://www.figma.com/design/JL8VTuKsb84VYhsgHhTJP0/HyundaiProject2026?node-id=97-4538)

## 실행

Android Studio에서 이 폴더를 열고 Gradle 동기화 후 `app`을 실행합니다. 빌드에는 JDK 17과 Android SDK 35가 필요하며, 실행 대상은 Android API 28 이상입니다. Windows 터미널에서 디버그 APK를 빌드하려면 다음 명령을 실행합니다.

```powershell
.\gradlew.bat :app:assembleDebug
```

빌드 결과는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다.

## 시연 순서

| 흐름 | 실행 방법 |
| --- | --- |
| Flow 1 · 비상등 메시지 | 기본 화면에서 메시지를 골라 확인합니다. `additional messages`를 누르면 6~10번 메시지에도 같은 절차가 적용됩니다. |
| Flow 2 · 좌회전 메시지 | 오른쪽 위 `시연` 메뉴에서 `Flow 2 · 좌회전 메시지`를 선택한 뒤 1~3번 중 하나를 고릅니다. |
| 전송 실패와 재전송 | 메시지를 고르기 전에 `다음 전송 결과 · 실패`를 선택합니다. 실패 안내 뒤 재전송 확인이 표시됩니다. `확인`을 누르면 동일 메시지를 다시 전송하고, `취소`를 누르면 현재 목록으로 돌아갑니다. 다음 요청의 기본 응답은 성공입니다. |
| Flow 3·4 · 수신 | 앱의 어느 화면에서든 `시연` 메뉴에서 경고 또는 일반 알림 수신을 선택합니다. 현재 화면 위에 알림이 나타납니다. 알림을 누르거나 자동 닫힘 시간이 지나면 보던 화면으로 돌아갑니다. |
| 음성 인식 표시 | `음성 인식 시연`으로 상단 표시와 인식 문구, 메시지 강조, 확인 화면을 순서대로 봅니다. Flow 2 실패 안내에서 `음성 재전송 시연`을 선택하면 음성 이벤트로 재전송 확인을 띄울 수 있습니다. |

화면 전환 시간이 지정되지 않은 곳에 시연용 값을 사용했습니다. 완료·실패 안내는 1.3초, 빨간 경고는 4초, 일반 알림은 3초 동안 표시됩니다. 완료 후에는 송신을 시작한 목록으로 돌아갑니다. 빨간 `Alert` 시안 두 장은 하나의 경고에서 강조 효과가 바뀌는 모습으로 연결했습니다. Android API 28~30에서는 배경을 어둡게 하고 API 31 이상에서는 흐림 효과를 함께 적용합니다.

## 연동 위치

- `MessageGateway.java`는 송신과 수신을 연결하는 인터페이스입니다. `send()`에는 메시지 코드, 문구, 요청 ID가 전달됩니다. 백엔드가 정한 전송 성공 시점에 `SUCCESS`를 돌려주고, 실패 시 `FAILURE`를 돌려주세요. 앱은 8초 동안 응답이 없을 때도 실패로 처리합니다. 재전송은 같은 요청 ID를 사용하므로 서버에서도 이 ID로 중복 전송을 막을 수 있습니다.
- `subscribe()`의 수신 이벤트에는 `CRITICAL` 또는 `NOTICE`, 문구, 필요한 경우 가린 발신자 표시를 전달합니다. 실제 연동에서는 `DemoMessageGateway`를 서버 어댑터로 교체합니다.
- 실제 음성 인식 서비스에서는 인식 시작과 종료, 인식 결과를 `MessagingController.startListening()`, `stopListening()`, `recognize()`에 메인 스레드에서 전달합니다. 시연 앱은 해당 이벤트를 메뉴에서 발생시킵니다.
- 앱 화면 바깥의 시스템 알림, 실제 차량 신호, 마이크와 서버는 연결 전입니다. 현재 `시연` 메뉴로 네 흐름을 재현할 수 있습니다.
